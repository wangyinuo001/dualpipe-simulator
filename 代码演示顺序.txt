当前展示布局

上半屏 1F1B、下半屏简化双向调度，各自左侧代码、右侧执行状态与任务时间轴。两组共用仿真时钟，默认 30× 同步播放；先完成的一组停留在完成状态，另一组继续执行。最终对照数字直接显示在页面底部。微批筛选只用于突出任务，不会改变同步时间。

代码与执行联动的现场版本

执行 python3 demo.py，或双击“启动演示.command”，默认进入左侧源码、右侧 GPU 状态的页面。选择一组实验并运行后，依次点击“下一步”，观察任务选择、启动和资源释放；左侧同步高亮对应代码。“找一次重叠”直接跳到同一 GPU 计算与通信同时占用的实际步骤，“看运行结果”显示这次运行的比较数据。三组实验可以逐组重新运行。

左侧是真实 simulate() 源码，执行记录由 debug_trace.py 用 sys.settrace 捕获。这里把相关源码行合为一次调度动作来讲，不是逐行点击执行 Python；运行已先完成，界面回看当时的变量与资源状态。若需要直接在编辑器中修改参数并运行文件，也可使用下面的方式。

这一版从真实 Python 文件开始讲，网页只用来检查输出。

第一步：在 VS Code、PyCharm 等编辑器里打开“课堂演示.py”。
展示 BASELINE 和 CASES：三个实验分别是基础条件、只增大通信耗时、只增大微批数量。两种方法共享同一份 Config。这里的 F、B、W、COMM 都是模型给定的耗时，不是测得的 GPU 算子耗时。

第二步：进入 dualpipe_a/simulator.py，展示实际使用的三段逻辑。
在 build_tasks() 中看 deps 和 resources：当前阶段前向要等前一个阶段的传输；反向要等本层前向与后续阶段传来的梯度。并行模式把 compute 和 communication 分成独立资源。
在 simulate() 中看 candidates：任务的 deps 必须全部出现在 completed 中，而且 resources 不能被 occupied 占用，才能进入候选集合。1F1B 额外受阶段队列限制；简化双向调度按 COMM、B、F、W 的优先级选择任务。
最后看 time = running[0][0]：仿真时钟跳到最近完成的任务，并释放相应资源。这是真正生成开始、结束时间的位置；绘图没有决定这些时间。

第三步：回到“课堂演示.py”，运行基础组。
点击编辑器运行按钮会运行默认的 baseline。也可以在本文件夹的终端执行：
python3 课堂演示.py --case baseline
Windows 将 python3 换成 python。

终端会输出两种资源模式、两种调度的耗时和加速比，并列出微批 0 的真实任务 ID、开始结束时间、依赖。还会打印 Python 程序本身的运行秒数，但它只表示调度器计算花了多久，不参与 GPU 调度性能比较。
完成后自动打开本次生成的“时间轴.html”。它是读取已生成事件的离线查看器，页面会明确标出生成时间和源码摘要；不需要运行网页服务，也不在网页里再次求解。

第四步：在左右联动界面中追踪具体任务。
默认停在初始化，左侧显示实际 simulate() 源码，右侧显示各 GPU 的计算、通信资源。点“下一步”，先看任务被选中，再点一次看它启动；继续推进到完成，观察资源释放。左侧同步高亮对应代码，下面的任务记录随启动新增、随完成填实。
“找一次重叠”跳到同一 GPU 计算与通信同时占用的步骤；“看运行结果”查看两种调度的总完成时间。可选择微批 0 缩小讲解范围，也可以切换串行/并行资源模式。完整对照图和截图导出在右上角“完整时间轴与导出”中。

第五步：回到编辑器/终端，运行另外两组。
python3 课堂演示.py --case high_comm
python3 课堂演示.py --case more_microbatches
每次都真实调用调度器，生成独立的输出文件夹；图表不是提前写好的答案。若要临时改变参数，直接修改 BASELINE 或 CASES 中相应字段，重新运行即可。

每次运行保存什么
“运行结果”中的每个子文件夹包含 events.json、四份事件 CSV、自包含的代码联动页面时间轴.html、时间轴总览.html，以及当时的入口与调度器源码快照。HTML 和 JSON 内有同一个运行编号，JSON 记录源码 SHA-256，可确认展示图与哪次程序运行对应。日后修改源码不会改变已有结果。

讲解边界
当前底层仍然是组员提供的简化双向优先级调度，不是官方 DualPipe 的完整局部重叠与全局调度复现。程序校验能证明模型内部依赖、资源约束和工作量一致，不能证明模型完整还原了论文。代码演示会如实暴露这个范围。相关原理应讲成启发与简化假设，不能用界面或动画代替模型正确性的说明。
